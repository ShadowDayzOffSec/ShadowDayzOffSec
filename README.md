### 👋 About Me

I'm a first-year BTech (CSE) student building offensive-security tooling as I learn — network & web app pentesting, recon automation, and CTFs, mostly from Kali Linux and Termux. I write my tools in Go and Python and try to make each one solve a specific, narrow problem well rather than reinventing the whole toolchain.

Currently exploring the intersection of **AI and defensive security research** — things like using LLMs to triage recon output and testing prompt-injection defenses, done under responsible-disclosure norms.

### 💥 Projects

<details open>
<summary><b>🍪 CookieCrumb — Cookie Security Analysis Framework</b></summary>
<br>

A Go CLI tool that extracts cookies from web apps and runs security analysis on them: Secure/HttpOnly/SameSite checks, entropy scoring, JWT detection, and session-cookie fingerprinting. Outputs JSON, so it chains into a normal recon pipeline (`subfinder | httpx | cookiecrumb`).

**Stack:** Go &nbsp;·&nbsp; **Status:** Actively maintained &nbsp;·&nbsp; [🔗 View Repo](https://github.com/ShadowDayzOffSec/cookiecrumb)

</details>

<details>
<summary><b>🔍 ReconX — Modular Recon Scanner</b></summary>
<br>

Python-based recon tool covering WHOIS, DNS enumeration, subdomain brute-forcing, port scanning, tech fingerprinting, directory fuzzing, and basic SQLi/XSS detection, with JSON reporting.

**Stack:** Python &nbsp;·&nbsp; [🔗 View Repo](https://github.com/Wolfnation01/reconx)

</details>

<details>
<summary><b>🕵️ StegoX — LSB Image Steganography</b></summary>
<br>

Hides files or text inside PNG/BMP images using LSB encoding, with optional AES-256 encryption. Built for CTF challenges and learning data-hiding techniques.

**Stack:** Python &nbsp;·&nbsp; [🔗 View Repo](https://github.com/Wolfnation01/stegox)

</details>

<details>
<summary><b>🔐 Cipher Toolkit — Classical Cipher & Encoding Engine</b></summary>
<br>

Command-line implementation of classical ciphers (Caesar, Vigenère, Affine, Rail Fence, XOR) and encoding formats (Base64/32/85, Hex, Morse), plus AES-256/Fernet password-based encryption. Built as a from-scratch cryptography exercise.

**Stack:** Python &nbsp;·&nbsp; [🔗 View Repo](https://github.com/Wolfnation01/ende-tool)

</details>
